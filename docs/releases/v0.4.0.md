# CC v0.4.0 — Guided plan and launch approvals

Approve a saved ticket plan or authorize repository launch from the Claude Code
session without copying a Python command:

```text
/cc:approve MSC-1873 --plan
/cc:approve MSC-1873 --implementation
```

The Skill reads the saved plan and effective approvals, presents the exact
revision and scope for explicit acceptance when needed, records only the accepted
scope, and verifies the resulting plan hash and approval states. Invoking the
Skill alone does not approve anything. Existing explicit acceptance of the same
unchanged revision and scope in the current conversation is respected.

Plan acceptance, implementation/launch authorization, and the repository worker's
native editing approval remain separate. The Skill does not launch a worker,
edit repository code, or perform delivery actions. Missing, placeholder, changed,
and legacy unbound plans retain the existing approval safeguards.

## Next-step guidance

Approval recommendations now support both `/cc:approve` and Python commands:

- `workflow.next_steps.display: "slash"` shows the Claude Code Skill.
- `"cli"` shows the Python terminal command.
- `"both"` shows both forms for the same action.

`max_suggestions: 1` continues to mean one recommended action. Standalone
compatibility Skills include `/cc-approve` for refreshed or newly created
workspaces. This release does not change the stored-status versus effective
approval-phase presentation; legacy approvals still require explicit reapproval.

## Update from a terminal

Run these outside Claude Code:

```bash
claude plugin marketplace update my-cc-marketplace
claude plugin update cc@my-cc-marketplace
claude plugin list
```

Restart Claude Code, then use `/cc:approve` in the same command-center workspace.
Do not rerun `/cc:init`. Tickets, plans, configuration, and context remain intact.
Plugin Skills use the updated bundled engine. Optionally run `/cc:upgrade` to
refresh the standalone `.cc/cc` engine; explicitly request
`/cc:upgrade --refresh-skills` if you also want generated standalone Skills.

Validation: all 27 automated tests pass, including both approval scopes,
slash/CLI/both rendering on plugin and standalone surfaces, read-only guidance,
and invalidation after plan changes. Static packaging and Claude Code plugin
and marketplace validation pass. Existing plugin directory license and icon
notices remain.
