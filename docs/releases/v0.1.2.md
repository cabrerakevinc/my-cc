# CC v0.1.2 — Local ticket dashboard

- Run `/cc:dashboard` in your command-center workspace to open a local, read-only browser dashboard.
- Search tickets and filter active, paused, or individual phases. Inspect plans, decisions, handoffs, repository work orders, and reported test results.
- Copy `/cc:resume TICKET` to continue in Claude Code. Refresh the page for updated state.
- Launch, reuse, and stop the local server through the skill or `dashboard` CLI command. No extra packages or AI service required.
- Serve only on loopback with a private URL token; read SQLite and ticket documents without changing ticket state.

## Upgrade

Refresh `my-cc-marketplace`, update `cc@my-cc-marketplace`, then restart Claude Code. Run `/cc:dashboard` from an existing initialized workspace: the skill uses the updated plugin engine even when the copied `.cc/cc` is older. Newly initialized workspaces also include the `dashboard` CLI and local `/cc-dashboard` skill.

The default port is 8765. Use `--port 0` for an available port and `--no-browser` to print the URL. Closing a browser tab leaves the server running; stop through the skill, `dashboard --stop`, or Ctrl+C in foreground mode. Keep the access URL private.

Validation: six automated tests cover existing persistence and repository launching plus dashboard HTTP behavior, filtering, escaping, access checks, refresh, reuse, and shutdown. Static packaging and Claude Code manifest validation also pass. Directory submission still reports the existing missing license and icon.
