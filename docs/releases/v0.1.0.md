# My CC v0.1.0 — Initial Release

**Release type:** initial pre-1.0 starter release. **Target date:** 2026-11-04.

## Highlights

- Claude Code marketplace packaging (`my-cc@my-cc-marketplace`) and namespaced `/my-cc:cc-init` skill.
- Portable workspace-local CLI plus optional global installer.
- Multiple independent command centers: engineering, business, academic, and general profiles.
- Durable per-ticket notes, approved plans, decision logs, and pause/resume checkpoints.
- Local SQLite ticket index, filtered sprint status, and repository registry.
- Supervised repo-specific Claude Code worktree launch with instruction awareness (`CLAUDE.md`, `AGENTS.md`, `AGENT.md`).
- Communications voice and business reference templates without mixing them into coding worker instructions.
- No automatic installation of external integrations or credential changes.

## Important limitations

TWG and AWS MCP CLI adapters are placeholders pending on-machine command discovery; this release does not create PRs, read Jira live, deploy, or update tickets automatically. The coding launcher has automated tests using a fake `claude` executable; test on the user's Mac before relying on it for company work. Plugin manifests must also be validated by the user's actual Claude Code CLI.

## Security

All local ticket state and workspace communication context are gitignored by default. Never commit secrets, real ticket contents, private company docs, logs, or credentials to this public source repository. Human authorization remains necessary for mutating actions.
