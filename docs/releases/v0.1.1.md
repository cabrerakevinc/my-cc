# CC v0.1.1

- Rename the marketplace plugin to `cc` and shorten its skills to `/cc:init`, `/cc:pickup`, `/cc:save`, `/cc:resume`, `/cc:status`, `/cc:work`, and `/cc:draft`.
- Preserve engineering workflows, durable ticket persistence, workspace initialization, and repository coding launcher.
- Add a README lifecycle diagram and a worked ticket example covering planning, approvals, pause/resume, implementation, test evidence, and delivery.
- Preserve legacy standalone and workspace-local `/cc-*` commands.

Install `cc@my-cc-marketplace`. Existing users should uninstall `my-cc@my-cc-marketplace`, update the marketplace, install the renamed plugin, and restart Claude Code. Existing workspaces need no migration.

The v0.1.0 release was already published; its tag and release must not be reused.
