# CC v0.2.0 — Configurable workflow guidance

My CC now reports the current ticket phase and a concise next action after Skills
and ticket commands, so you can follow the workflow without memorizing it.

- Configure `workflow.next_steps` in `workspace.yaml` or the existing
  `workspace.json`: `enabled`, `display` (`slash`, `cli`, `both`), and
  `max_suggestions`. Defaults are enabled, both formats, and two actions.
- Explicit JSON values override YAML per setting. JSON-only workspaces work
  without migration; missing settings use defaults.
- Recommendations use persisted ticket state and effective content-bound
  approvals. Blocked and paused tickets receive handoff guidance; implementation
  is suggested only after the required approvals.
- Claude Code and terminal commands have distinct labels. Unsupported equivalents
  are omitted; suggested commands are never automatically executed.
- Keep native `/plan` in the pickup session. Save a finalized plan with
  `/cc:save TICKET`; My CC installs no hook to infer native planning completion.
  The read-only `next-steps TICKET --plan-finalized` query provides a manual hint.

This release also includes the native-plan persistence and workspace upgrade
improvements made since v0.1.2: complete plan imports, revision-bound approvals,
full saved plans on resume and worker launch, and safe compatibility refreshes.
Plan acceptance, implementation/launch authorization, and native worker approval
remain separate gates.

## Update an existing Claude Code installation

Run in Claude Code:

```text
/plugin marketplace update my-cc-marketplace
/plugin update cc@my-cc-marketplace
/reload-plugins
```

Restart Claude Code if your installed version requires it. Use `/cc:pickup`,
`/cc:resume`, and the other namespaced Skills in your existing command-center
workspace. Do not rerun `/cc:init`; tickets, configuration, context and saved
plans remain local and intact.

Optionally run `/cc:upgrade` to refresh the workspace's terminal `.cc/cc` copy.
To refresh unchanged generated standalone Skills as well, explicitly request
`/cc:upgrade --refresh-skills`. Customized Skills are preserved.

See [guidance configuration](../NEXT-STEPS.md), the
[planning workflow](../PLANNING-WORKFLOW.md), and the
[upgrade guide](../UPGRADING.md).
